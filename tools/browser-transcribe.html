BROWSER AUDIO → TEXT / v0.2.0

浏览器里的声音，
变成可以编辑的文字。

无需 API Key、音频驱动或本机 Python。录音和识别在当前浏览器中进行。
首次识别需联网下载模型；这不是粘贴链接后自动抓取视频的工具。

检查浏览器能力中…

01

获取完整音频

  1. 在同一浏览器的另一个标签页打开视频，暂停在开头。
  2. 点击“录制标签页声音”，在弹窗中选择该视频标签页，并勾选“共享标签页音频”。不要选整块屏幕。
  3. 回到视频标签页，以正常速度从头播到尾；不要跳转、倍速或混入广告。结束后返回这里，停止录音。

尚未开始录音。不会使用麦克风。

文件仅在本机读取。支持情况取决于浏览器的音频解码器。

02

在浏览器本地转写

默认模型以体积优先，不保证中文识别准确。专有名词、数字、命令和提示词必须回听核对。

先录音或选择音频文件，再开始。长录音建议分段处理并注明时间范围。

自动识别 · 待核对

没有转写结果。录到全程不等于逐字准确，也不等于已覆盖全部关键画面。

开始前，请了解这些边界

  • 请用支持标签页音频共享的桌面浏览器。Chrome / Edge 是建议路径；Safari、手机或内置浏览器不保证支持。没有音轨会明确报错，不会冒充录音成功。
  • 录音和识别不向本站或转写 API 上传音频。模型、WASM 和固定版本的识别库从 Hugging Face 与 jsDelivr 下载，网络供应方会收到正常资源请求。首次下载可能需要数分钟，也可能受网络限制。
  • 识别只处理你录到或提供的音频；不会自动验证视频开头、结尾、广告、静音、缺漏或画面内容。JSON 会记录处理时长，且始终标为待核对，不能自动登记“完整原稿”。
  • 音频保留在当前页面内存中，刷新页面会丢失，建议先保存备份。模型可能保存在浏览器缓存中；清除网站数据可清理相关缓存。失败时保留音频，改用本地转写路径，不必重新录制。
  • 浏览器共享权限必须由使用者自己选择，Skill 无法绕过权限弹窗、平台访问或版权限制。录制受限内容也可能只有静音。
