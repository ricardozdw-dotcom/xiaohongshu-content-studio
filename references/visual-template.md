# 多风格小红书版式

设计资源是 assets/styles.json、carousel.css 与 carousel-themes.css。reference-cover.png 和 reference-content.png 仅代表原版 editorial。风格选择不依赖旧聊天、作者电脑或在线图像服务。

## 五套预设

| style | 名称 | 适合内容 | 视觉区别 | 默认封面 |
| --- | --- | --- | --- | --- |
| editorial | 经典书页 | 深度解读、访谈笔记 | 白底宋体、灰划线、蓝编号，保留原版 | photo |
| tech | 深色科技 | AI 资讯、模型发布、工具解析 | 墨蓝网格、荧光绿、终端框、线性编号 | type |
| cards | 清爽卡片 | 教程、清单、步骤指南 | 浅蓝底、白信息卡、胶囊标签、独立步骤卡 | type |
| notebook | 暖色手账 | 学习复盘、个人观察 | 奶油纸、边栏线、荧光笔、便签引用 | type |
| poster | 大字海报 | 短观点、误区提醒 | 黄黑高对比、大标题、粗分隔、反白结论 | type |

每套同时定义封面和内页，不是只换一个背景色。全部支持 photo / type。photo 必须有图片；type 用真实文字与 CSS 几何构图，不依赖 ImageGen。默认有 image 则用 photo，无图则按该风格默认值；editorial 无图需显式写 layout: type。省略 style 保持旧计划的 editorial 行为。

## 选择方法

1. 用户明确指定、品牌要求或参考图优先于内容推荐。参考超出预设时说明最接近的一套与区别；要精确复现，另做任务级样式并完整验收，不谎称预设已支持。
2. 未指定时先看内容结构，再选视觉：步骤多选 cards，信息更新选 tech，个人复盘选 notebook，深读选 editorial，短而有力的单点观点选 poster。简短告知所选和理由即可，不为常规选择反复询问。
3. 用户要“尝试多种”时，用同一封面文字与代表内页做 2–3 套预览。明确推荐并展示区别；预览不等于用户确认了新稿，也不能打成正式发布包。
4. 同一套轮播统一风格。若任务目录有上次 style，作为历史参考；新主题仍判断适配性，不随机轮换，不依赖所有使用者共享一份偏好文件。
5. 长教程不为海报感删步骤，优先换成更适合的风格或增页。代码保持原字符，完整副本另附 TXT。

## 字体与画布

- 1080×1800 PNG，安全留白一般为 66–112 px；每页标题、正文、页脚有稳定层级。
- 标题约 59–99 px，正文约 36–38 px，提示词约 33 px，代码约 28 px；无中文字体时先解决字体，不能接受方框或空白。
- 不因换风格压缩至难读字号；不能用固定 7/9 页限制教程。
- 海报默认留白较大，教程卡片信息密度较高；留白不是需要自动填满的错误。
- 小标题、引用、步骤、时间表与代码块均适配各风格；小字仅做来源等辅助信息，不承载关键操作。
- 署名由用户指定，未指定时不使用之前作者的品牌名。

## 封面与连续阅读

封面先让人知道主题，不制造未证实的震惊、收益保证或“亲测”。标题分 2–3 行，避免孤立一两个字。照片与主题相关，不默认名人、不沿用其他话题照片。生成照片标注 AI 示意，保存最终提示词；真实截图不能伪造。纯字封面不得标为 AI 照片或放无关的照片来源说明。

封面 → 前置背景 → 观点或操作 → 验证与提醒。页面数量随内容变化。每张独立可读，但前后依赖不可断裂。文字内容已确认才制作正式稿；只换字体、配色、布局可沿用同一稿件确认，改变事实、步骤或关键结论须重新确认。

## 验收

自动检查宽高、图片加载、横纵溢出、页脚及正文间距。之后逐张查看 PNG，核对中文字形、对比度、字号、断行、孤行、遮挡、技术文字和步骤顺序。装饰不得干扰阅读；不能只有封面好看而内页仍套旧版。图中自动换行不得更改命令的原始字符。

发布正文可短，说明图片在讲什么。标签相关，评论不虚构领取方式或成果。匿名示例与预览报告不冒充用户成稿。
